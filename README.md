# Director Story Showcase

## Overview

Director Story Showcase is a full-stack MERN application that connects Directors and Producers. Directors can showcase stories, scripts, and creative projects, while Producers can discover talent, review content, and interact through likes and comments.

---

## Features

### Director

* Register and Login
* Create and Manage Profile
* Upload Stories and Creative Content
* Showcase Portfolio
* Manage Published Projects

### Producer

* Register and Login
* Browse Director Profiles
* View Director Stories
* Like and Comment on Posts
* Discover Creative Talent

### General Features

* JWT Authentication
* Role-Based Access Control
* Responsive UI
* Public Profiles
* Like & Comment System
* Genre-Based Filtering

## Installation

### Clone Repository

```bash
git clone https://github.com/sakthi2300/Director_Story_Showcase.git
```

### Install Dependencies

```bash
npm install
```

### Run Frontend

```bash
cd frontend
npm run dev
```

### Run Backend

```bash
cd backend
npm run dev
```

### Environment Variables

Create a `.env` file:

```env
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
PORT=5000
```
